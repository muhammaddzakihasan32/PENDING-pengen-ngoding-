# PENDING-pengen-ngoding-

Proses bisnis: Sistem mendigitalkan alur kerja agensi kreator mulai dari (1) Pencatatan Kontrak antara Kreator dan Brand; (2) Pelacakan Produksi Konten di mana Kreator memperbarui status pekerjaan (Brief, Produksi, Review, Publish) yang dapat dipantau langsung oleh Brand dan Manajer; hingga (3) Kalkulasi Bagi Hasil otomatis antara Kreator dan Agensi (meskipun proses transfer uangnya dilakukan di luar sistem). Seluruh komunikasi terkait revisi juga didokumentasikan melalui fitur chat internal.

Masalah: Pengelolaan kontrak kerja sama yang masih manual/tersebar, kurangnya transparansi status produksi konten,serta perhitungan bagi hasil yang memakan waktu dan berpotensi menimbulkan perselisihan antara agensi dan kreator.

Pelaku: Kreator, Brand, dan Talent Manajer
